# Instruções para agentes de código

Leia e siga **[AI_RULES.md](AI_RULES.md)** antes de qualquer mudança neste
projeto. As regras moram só lá; este arquivo existe para os assistentes que
procuram `AGENTS.md` (Codex, Cursor e outros).

A regra absoluta, em resumo: quem modificar, adicionar ou remover
funcionalidades, alterar a arquitetura ou mexer nas lógicas do motor atualiza
o `README.md` e o `docs/GDD.md` na mesma entrega. A documentação é sempre a
fonte da verdade exata do código atual.

O projeto inteiro está explicado no [README.md](README.md).
